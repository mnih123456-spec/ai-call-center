Wgraj pliki `index.html` i `style.css` z katalogu `strona/` do katalogu publicznego zwykłego hostingu (najczęściej `public_html`, `www` lub `htdocs`), zachowując je obok siebie; strona nie wymaga instalacji, budowania ani połączenia z usługami zewnętrznymi, a ilustracja jest osadzona w HTML. Przed publikacją uzupełnij sekcję kontaktu w `index.html` prawdziwym adresem e-mail i numerem telefonu jako odnośnikami `mailto:` i `tel:` - dane nie zostały jeszcze podane.
